# User Story Map — AI Learning Environment

![User story map](User%20Story%20Map.png)

The map follows a student from left to right: set up courses, read, get help, practise,
prepare for exams, manage the plan. Release 1 is the ENSE 400 scope (due 1 December 2026).
Release 2 is ENSE 477 (Winter 2027, tentative). Requirement IDs refer to
`05. Project Requirements.pdf`.

## Release 1 — Fall 2026 (ENSE 400)

| Activity | Story | Req. |
|---|---|---|
| Set up my courses | As a student, I want to add a local folder as a course, so that the app works from the files I already have. | FR-1 |
| Set up my courses | As a student, I want to see my PDFs listed by course, so that I can find the file I need quickly. | FR-1 |
| Set up my courses | As a student, I want to read what text is sent to which AI provider, so that I can decide what I am comfortable sharing. | FR-10 |
| Set up my courses | As a student, I want to remove folder access at any time, so that I stay in control of my files. | FR-1 |
| Read my course files | As a student, I want to open a PDF in a built-in reader, so that I do not have to switch apps to study. | FR-2 |
| Read my course files | As a student, I want to navigate, zoom and search a PDF, so that I can move around long lecture slides and chapters. | FR-2 |
| Read my course files | As a student, I want to select a passage or a whole page, so that the AI knows exactly what I am asking about. | FR-3 |
| Read my course files | As a student, I want to be told when a page is scanned, so that I understand why I cannot select its text. | FR-12 |
| Get help understanding | As a student, I want to ask a question by typing, so that I can get help on the passage in front of me. | FR-4 |
| Get help understanding | As a student, I want every explanation to show its file and page, so that I can check it against the source. | FR-5 |
| Get help understanding | As a student, I want to jump to the cited page, so that checking an answer takes one click. | FR-5 |
| Get help understanding | As a student, I want to pick a model from cheapest to most expensive, so that I choose my own trade-off between cost and quality. | FR-6 |
| Get help understanding | As a student, I want the app to switch to another free model when one is busy, so that my study session is not interrupted. | FR-11 |
| Practise | As a student, I want to generate flashcards from a passage, so that I do not have to write them by hand. | FR-7 |
| Practise | As a student, I want to edit, delete and save flashcards, so that my deck only holds cards I trust. | FR-7 |
| Practise | As a student, I want to generate a quiz from a passage, so that I can test myself on what I just read. | FR-8 |
| Practise | As a student, I want instant marking with page references, so that I can go straight back to what I got wrong. | FR-8 |
| Practise | As a student, I want to reopen saved explanations, cards and quizzes per course, so that I can pick up where I left off. | FR-9 |

## Release 2 — Winter 2027 (ENSE 477, tentative)

| Activity | Story | Req. |
|---|---|---|
| Set up my courses | As a student, I want to sign up and sign in, so that my plan and usage follow my account. | FR-13 |
| Read my course files | As a student, I want to read my files on an iPad, so that I can study away from my laptop. | FR-19 |
| Read my course files | As a student, I want scanned pages turned into text, so that I can ask about them too. | FR-18 |
| Get help understanding | As a student, I want to ask by speaking, so that I can ask questions hands-free. | FR-17 |
| Get help understanding | As a Pro student, I want to use paid models, so that I get stronger explanations when I need them. | FR-14 |
| Prepare for exams | As a student, I want to enter my exam dates, so that review is planned around them. | FR-16 |
| Prepare for exams | As a student, I want a daily review queue, so that I know exactly what to review each day. | FR-16 |
| Prepare for exams | As a student, I want to review flashcards on an iPad, so that I can review anywhere. | FR-19 |
| Manage my plan | As a student, I want to subscribe to Pro, so that I can unlock paid models. | FR-14 |
| Manage my plan | As a Pro student, I want to manage or cancel my subscription, so that I stay in control of what I pay. | FR-14 |
| Manage my plan | As a Pro student, I want to see my monthly usage, so that I know how much I have left. | FR-15 |
| Manage my plan | As a Pro student, I want to fall back to free models at my limit, so that I can keep studying. | FR-15 |
