# Documents

The documents for **Funza Teacher Studio**. The folders follow the order of the capstone: research, then planning, design, development, testing, presentations, the user guide and closing.

**[document_tracker.md](document_tracker.md)** lists every document the project needs, where it goes, what it must contain and how far along it is.

| Folder | What goes in it | Course stage |
|---|---|---|
| [`01_research/`](01_research/) | Who the users are, what they need, competitors, business model, teacher interviews | Design Workshops 1–2 |
| [`02_project_plan/`](02_project_plan/) | Business case, charter, stakeholders, scope, schedules, roles, user story map, Gantt chart, risks | Design Workshop 3 |
| [`03_design/`](03_design/) | User flows and features, requirements and architecture, UI design | Design Workshop 4, Development Workshop 1 |
| [`04_development/`](04_development/) | Build plan, weekly status reports, code review | Development Workshops 1–3, scrums |
| [`05_testing/`](05_testing/) | Code and usability test plans and results | Usability evaluation, ENSE 477 |
| [`06_presentations/`](06_presentations/) | Work-in-progress demo, vlogs, poster, demo video, commercial, final presentation | Bazaar day, vlogs, ENSE 477 |
| [`07_user_guide/`](07_user_guide/) | Help and training for teachers | ENSE 477 |
| [`08_closing/`](08_closing/) | Retrospective, project experience report | End of each term |
| [`archive/`](archive/) | Documents for the products we built before Teacher Studio, kept as submitted | Sept–Oct 2026 |

## Naming and storage

These rules are the project's documentation guidelines.

- **Names are lowercase `snake_case`.** A file is `NN_name.ext`, numbered in reading order within its folder. A folder is `NN_name`.
- **One document, one number.** When a document is kept in two formats (for example `.pptx` and `.pdf`), both files share the number.
- **A document with images gets its own folder**, with the document and a `diagrams/` folder inside.
- **Write in Markdown** where possible, so the document reads well on GitHub and its history is visible. Slides and posters are kept as the source file plus a PDF.
- **Version and date on the second line** of every document, for example `**Funza Teacher Studio · v0.1 · 21 November 2026**`.
- **Videos are links**, not files. Upload to unlisted YouTube and put the link in the document's folder; GitHub rejects files over 100 MB.
- **Course material stays out of the repo.** The instructor's slides, templates and course page are kept in the git-ignored `local/` folder.
- **No names of interviewees or students** without their agreement.
